# 实验 A：几何面偏移（成像面 ±3mm × 反射面 ±1mm）

脚本：`exp/plane-offset/plane_offsets.py`
运行：`uv run python exp/plane-offset/plane_offsets.py`

> **时间线注记**：下方数值是在**旧圆心提取**（局部±30px + 阈值0.3，baseline σ≈216μm）
> 下得到的，当时结论是"成像面偏移无收益"。**后来圆心提取改进后**（大窗口+高阈值，
> baseline σ≈106μm，见 `exp/centroid/`），重跑本脚本发现**成像面 +3mm 反而略优
> （96 vs 106μm）**——旧提取的噪声曾掩盖了 3mm 的真实信号。即：成像面 +3mm 假设
> 在低噪声下可能成立，值得在新提取基线上重新评估。反射面偏移仍无明确物理依据。

## 动机（用户假设 + 文档依据）

- **成像面 +3mm**：PnP 标的是毛玻璃近相机面(Z=0)，激光实际打在毛玻璃远相机面
  （厚 3mm）→ 成像面可能应沿法向向远离相机方向偏 +3mm。（device-physical-spec §1、§105）
- **反射面 +1mm**：反射镜厚约 1mm，当前用前表面，可能应用后表面 → 沿法向 +1mm。（§3）

几何偏移不改圆心像素，从 `1-Spot-Center.csv` 像素重跑反投影链比组内 σ。

## 2×2 结果

| 成像面 | 反射面 | 平均 σ/μm |
|---|---|---|
| **0mm** | **0mm** | **215.8（当前）** |
| 0mm | +1mm | 227.8 |
| +3mm | 0mm | 223.1 |
| +3mm | +1mm | 229.0 |

**用户的两个假设（成像面+3mm、反射面+1mm）都让 σ 变差，不改善。** (0,0) 自洽复现 baseline。

## 连续扫描（看最优真实位置与方向）

成像面偏移（反射=0）：
```
 -6mm 225.7 | -3mm 218.8 | -1mm 216.0 | 0mm 215.8 | +1mm 216.8 | +3mm 223.1 | +6mm 246.4
```
→ **成像面最优在 0mm**，两侧都变差。当前 PnP 标定的 Z=0 面就是最佳，不该偏移。

反射面偏移（成像=0）：
```
 -3mm 205.8 | -2mm 204.5 | -1mm 207.8 | 0mm 215.8 | +1mm 227.8 | +2mm 243.0 | +3mm 260.6
```
→ **反射面最优在约 −2mm**（σ=204.5，比当前好 11μm），方向与用户猜测（+1mm 后表面）**相反**。

## 结论与解读

1. **成像面 +3mm 假设不成立**——最优在 0，当前标定正确。
2. **反射面**：+1mm（后表面）假设方向错了；数据偏好 **−2mm**（更靠前），能降 σ ~11μm(5%)。
3. **谨慎**：−2mm 无明确物理依据（镜厚仅 1mm，−2mm 超出镜厚）。这很可能是**又一次
   "单参数吸收其它误差"的过拟合**（同几何自标定的教训：σ 降一点但参数跑离物理真值）。
   −2mm 改善幅度（11μm）和几何自标定能榨的量级相当，都远小于像素噪声主导的部分。

**总判断**：几何面位置不是方差的主要杠杆。成像面维持 0；反射面 −2mm 是可疑的小改善，
不建议在缺乏物理依据下采用。降方差的主战场仍在测量端（圆心提取，见实验 B）。
