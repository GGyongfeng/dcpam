# exp/ — 降方差优化实验

DCPAM 测量重复度（组内 σ）优化过程中尝试过的几个方向。每个子目录含该方向的
Python 脚本 + 结论（README.md）。都从项目根运行（`uv run python exp/<方向>/<脚本>.py`）。

| 方向 | 目录 | 结论 | σ 影响 |
|---|---|---|---|
| **圆心提取改进** | `centroid/` | ★ 决定性突破，已落地 | **216 → 106μm（−51%）** |
| 平面平移 | `plane-offset/` | 成像面 +3mm 在低噪声下可能有小收益，反射面无据 | 旧基线无收益；新基线 +3mm 略优 |
| 几何自标定 | `geometry-selfcal/` | 几何已近真值，瓶颈在测量端 | ~5%（有限） |

**总结论**：方差的主要杠杆在**圆心提取**（光斑大而饱和，旧的小窗口+低阈值让重心被
拖尾拉偏），而非几何参数。`centroid/` 的改进已合入产品代码
（`dcpam/steps/spot_extraction.py`：窗口 30→150、阈值 0.3→0.8）。

各方向的 σ 绝对值随"当前圆心提取基线"变化，比较时注意各 README 的时间线注记。
