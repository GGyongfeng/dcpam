# 几何自标定发现记录

脚本：`exp/geometry-selfcal/geometry_selfcal.py`
运行：`uv run --with scipy python exp/geometry-selfcal/geometry_selfcal.py --lam 0.1`

> **时间线注记**：下方数值基于**旧圆心提取**（baseline σ≈216μm）。核心结论
> "几何参数已近真值、σ 主导来源是圆心提取噪声、自标定只能榨 ~5%"在圆心提取改进后
> 得到印证——提取改进（见 `exp/centroid/`）把 σ 直接从 216 腰斩到 106μm，正是"瓶颈在
> 测量端而非几何"的直接证据。result.toml 是旧基线下的候选，如需可在新基线上重跑。

## 方法

用各组重复测量的**组内方差**作主目标，反求 `config.toml [geometry]` 的真值
（bundle adjustment / self-calibration）。

- **前向模型**（纯 numpy，已验证与 pipeline 逐组 σ 一致）：相机系 real 点
  c1/c2 →（camera_to_frame 固定）→ 取景框局部系 → rear 经 rear_to_front 并入设备系
  → 反射镜镜像得虚像 → 点到激光线(前虚像→后虚像)的距离 = 靶点到该线垂距 → 每组方差。
- **优化变量（20 维）**：rear_to_front(rvec3+t3)、前/后反射镜(各 point3+normal 球坐标2)、
  靶点 root(3)+杆长(1)。camera_to_frame 是标定产物，固定不优化。
- **目标函数**：`组内方差均值(mm²) + λ·Σ((参数−物理真值)/尺度)²`。真值锚来自
  `docs/device-physical-spec.md`（镜面 45°、间距 80mm、旋转≈I、杆长 586.051…）。
- **优化**：MC 粗搜 + scipy Nelder-Mead 精修；分阶段（先靶点+rear_to_front，再放开镜面）。
- **防过拟合**：用户选不留验证集，故靠真值正则 + 打印每参数偏离真值多少人工核。

## 结论（诚实、重要）

**几何自标定把平均 σ 从 215.8 → 204.7 μm，仅改善约 5%；且所有参数稳稳落在物理真值附近**
（镜面 44.97°/45.03°、间距 80.04mm、rear_to_front 旋转 0.009°、杆长 586.04、
靶点 root 偏 <0.05mm）。

即使把正则 λ 降到 0.01（几乎不约束），σ 也只到 204.6μm、参数仍几乎不动——
**手动扫靶点 root.x 确认最优在 +4mm 处 σ≈205μm，与优化器一致，说明没陷局部最优、是真的到顶了。**

两点一起说明：
1. **当前 geometry 已接近真值**（参数放开也不跑飞，反过来验证了标定的正确性）。
2. **σ 的主导误差源不是几何参数，而是圆心提取的像素噪声**（此前已发现 σ 与虚拟点
   z 方向离散强相关 0.944，经 ~740mm 杠杆放大）。几何自标定动不了像素噪声。

## 启示（下一步该往哪使劲）

要把 σ 降到 205μm 以下，**不在几何参数上，而在测量端**：
- 改善圆心提取精度（当前跨图 std 已 0.3~0.7px，属亚像素级，进一步需更好算法/相机）。
- 减小 z 方向杠杆敏感度（光路/靶点几何设计，非软件）。
- 更干净的采集（曝光一致、减少采集期漂移）。

自标定的价值兑现为：**确认几何已标定到位、无需再调**，并给出一组各方向都最优的
geometry 候选（`geometry_selfcal_result.toml`），可选择性合入。改善虽小（5%）但方向都对、
无过拟合，是可信的微调。
