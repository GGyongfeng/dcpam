# 基于标定数据的坐标统一算法思路

本文整理当前双相机光路在完成光斑圆心拟合之后的几何计算流程。
目标是把前、后相机各自拍到的激光光斑点，转换到同一个三维坐标系中，
为后续重建激光空间直线、计算目标点到激光线距离提供输入。


## 1. 设备与坐标系

系统由前、后两个相机模块组成。前相机模块中，激光先打到前方
45 度附近的半透半反镜，再反射到毛玻璃接收屏上，由前相机拍摄。
后相机模块中，光束透过前模块的半透半反镜，继续到后方第二个
半透半反镜，并同样由毛玻璃接收屏承接图像、后相机捕捉。

后续计算不直接使用物理安装的 45 度作为几何真值，而以标定数据为准。
设备坐标系统一选为前相机坐标系 `C_f`。后相机坐标系记为 `C_r`。
所有经过后相机求得的三维点，最终都转换到 `C_f` 中。


## 2. 标定数据来源

飞书文档《标定数据》给出了当前算法需要的三类参数。

第一类是相机内参。前相机和后相机都采用 `SIMPLE_RADIAL` 模型，
图像分辨率为 `2592 x 1944`。

```text
Camera_F: f = 2918.3027117633778, cx = 1296, cy = 972, k = -0.21368578685184925
Camera_R: f = 3757.720402939839,  cx = 1296, cy = 972, k = -0.23842116008477593
```

第二类是四个平面的外参标定结果：前接收屏、后接收屏、前反射屏、
后反射屏。文档中分别通过 “标定板在接收屏” 与 “标定板在反射屏”
两组 COLMAP `images.txt` 风格结果记录。接收屏标定时，标定板固定在
毛玻璃内侧的标定位置；实际拍摄和镜像计算使用的是毛玻璃外侧面，
因此接收屏平面应按当前确认的 `Z + 5 mm` 口径修正到实际成像面。

第三类是后相机相对前相机的位置。文档对五组相对位姿取均值，
平移取算术平均，旋转取算术平均后再用 SVD 投影为旋转矩阵，得到
`T_r_from_f`：

```text
[0.99981958, -0.01442669, -0.01235624, -7.86547923]
[0.01451016,  0.99987232,  0.00669294,  0.15503238]
[0.01225810, -0.00687103,  0.99990126,  0.70268141]
[0.00000000,  0.00000000,  0.00000000,  1.00000000]
```

该矩阵名字表示从前相机坐标系到后相机坐标系的变换。若算法最终以
前相机坐标系为统一坐标系，则需要使用它的逆矩阵 `T_f_from_r`。


## 3. 外参到平面方程

COLMAP 的单张图像外参通常表示为：

```text
x_camera = R * x_board + t
```

标定板自身坐标系中的板面为 `z = 0`。因此，标定板对应的物理平面
在相机坐标系中的方程可以写为：

```text
n = R[:, 2]
d = -n^T * t
n^T * x + d = 0
```

其中 `n` 是单位法向量，`d` 是平面常数项，`x` 是相机坐标系中的三维点。
接收屏外参用于得到接收平面，反射屏外参用于得到半透半反镜所在平面。

需要注意，前、后模块各自有自己的相机坐标系。因此，前接收屏与前反射屏
的平面方程位于 `C_f` 中；后接收屏与后反射屏的平面方程位于 `C_r` 中。


## 4. 像素圆心到接收屏三维点

Pipeline 先对前、后图像进行圆心拟合，得到像素点：

```text
p_f = [u_f, v_f, 1]^T
p_r = [u_r, v_r, 1]^T
```

使用内参矩阵把像素点转换为相机坐标系下的视线方向：

```text
ray_f = normalize(K_f^-1 * p_f)
ray_r = normalize(K_r^-1 * p_r)
```

更稳妥的三维化方式不是使用固定深度 `Z_s`，而是让这条相机光线与
对应接收屏平面求交。对任意接收屏平面 `n^T x + d = 0`，光线从相机
光心出发，可写为 `x = lambda * ray`。交点为：

```text
lambda = -d / (n^T * ray)
P_real = lambda * ray
```

这样得到的 `P_f_real` 位于前相机坐标系 `C_f`，`P_r_real` 位于后相机
坐标系 `C_r`。接收屏标定平面需要先修正到毛玻璃外侧的实际成像面，
当前按 `Z + 5 mm` 处理，再做相机射线与接收屏平面的求交。


## 5. 接收屏点到虚像面点

激光真实打在毛玻璃接收屏上，但为了还原展开后的光路，需要把接收屏上的
实像点关于对应的反射屏平面做镜像。对平面 `n^T x + d = 0`，点 `x` 的
镜像点为：

```text
x_mirror = x - 2 * (n^T * x + d) * n
```

也可以写成齐次矩阵形式：

```text
M_plane =
[I - 2nn^T, -2d n]
[0 0 0,          1]
```

于是前、后模块分别得到：

```text
P_f_virtual = M_f_reflector * P_f_real
P_r_virtual_in_Cr = M_r_reflector * P_r_real
```

这里的 `M_f_reflector` 由前反射屏平面生成，作用在 `C_f` 中；
`M_r_reflector` 由后反射屏平面生成，作用在 `C_r` 中。


## 6. 后相机点转换到前相机坐标系

完成镜像之后，前虚像点已经在统一坐标系 `C_f` 中。后虚像点仍在 `C_r`
中，需要通过相机相对位姿转换到 `C_f`。

若标定文档中的矩阵为：

```text
P_r = T_r_from_f * P_f
```

则后相机点到前相机坐标系的转换为：

```text
T_f_from_r = inverse(T_r_from_f)
P_r_virtual_in_Cf = T_f_from_r * P_r_virtual_in_Cr
```

到这一步，`P_f_virtual` 与 `P_r_virtual_in_Cf` 已经处于同一个前相机
坐标系内，可以共同定义激光空间直线。


## 7. 后续距离计算接口

统一坐标系后的激光线由两个虚像点确定：

```text
L0 = P_r_virtual_in_Cf
L1 = P_f_virtual
direction = L1 - L0
```

任意目标点 `P_target` 到该直线的距离为：

```text
distance = norm((P_target - L0) x direction) / norm(direction)
```

因此，当前阶段算法建议把 pipeline 拆成四个清晰步骤：光斑圆心提取、
基于内参和接收屏平面的反投影、基于反射屏平面的镜像变换、后相机到
前相机的坐标统一。每一步都只消费上一阶段的明确几何对象，避免把固定
安装角、固定深度和相机相对位姿耦合在同一个变换里。
