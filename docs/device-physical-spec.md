# 设备物理尺寸说明

本文档记录 DCPAM 样机的物理结构尺寸，作为算法配置（`config.toml`）与实测数据（例如关节臂采样）之间的对照基准。

数值约定全部使用毫米（mm）。


## 1. 取景框 + 毛玻璃叠层

每个相机模块（前、后）的取景端是一组同心叠装的物理面：

```
                                     朝向相机一侧
   ┌──────────────────────────┐
   │       取景框 2 mm        │   ← 取景框-近相机面
   ├──────────────────────────┤   ← 取景框-远相机面 = 毛玻璃-近相机面
   │      毛玻璃片 3 mm       │
   │     （承接屏 / 散射屏）   │
   └──────────────────────────┘   ← 承接屏-远相机面
                                     远离相机一侧
```

物理尺寸：

- **取景框厚度**：2 mm
- **毛玻璃（承接屏）厚度**：3 mm
- **取景框近相机面 ↔ 承接屏远相机面 总厚度**：5 mm
- 毛玻璃**紧贴**取景框装配，没有间隙

激光实际打在毛玻璃上形成漫散射，相机隔着取景框开口拍到这个散射面。


## 2. 算法实像面（Z = 0）的定义

算法配置 `config.toml` 中 `device.geometry.front_frame.point = [0, 0, 0]` 与 `rear_frame.point = [80, 0, 0]` 定义的"设备实像面"，**位于上面 5 mm 叠层的中间**，等效划分如下：

```
┌─────── 取景框 2 mm ────────┐
                              ← 设备 Z = 0 算法实像面（=取景框/毛玻璃交界面）
┌──────  毛玻璃 3 mm ────────┐
```

也就是说，**算法 Z = 0 平面 = 取景框近相机面向远相机方向 2 mm 处 = 毛玻璃近相机面**。
这一面也是 PnP 取景框位姿的目标面：PnP 的世界坐标 `Z = 0` 与算法 Z = 0 重合。

**Z 轴正方向 = 毛玻璃方向（即远离相机的方向）**。所以：

- 取景框远相机面：Z = 0
- 取景框近相机面：Z = −2
- 毛玻璃近相机面：Z = 0（与取景框远相机面重合）
- 毛玻璃远相机面：Z = +3


## 3. 反射镜（分光片）

每个模块在毛玻璃前方放置一片 45° 倾斜的反射镜（分光片）：

- **物理厚度**：约 1.05 mm（关节臂实测 1.04~1.06 mm）
- **与承接屏夹角**：45°（关节臂实测 45.22°）
- **算法引用面**：当前 `config.toml` 中 `device.geometry.{front,rear}_reflection` 描述的是反射镜**前表面**（靠承接屏一侧）

反射镜两面严格平行（实测 < 0.06°），算法用单面近似（忽略 1 mm 镜片厚度产生的折射偏置）。


## 4. 模块布置

前、后两个相机模块在设备 X 方向并排：

- **前模块原点**（前取景框 Z=0 面中心）：`[0, 0, 0]`
- **后模块原点**（后取景框 Z=0 面中心）：`[80, 0, 0]`
- **两模块间距**：80 mm（关节臂实测在承接屏面内 79.74 mm）

两个承接屏几乎共面（法向夹角 < 0.1°），即两个 Z=0 面在设备坐标系下平行。


## 5. 探测杆

探测杆固定在底板上方，靶点在杆末端：

- **杆根位置（设备系）**：`[41, 37, −132]` mm
- **杆长**：109 mm（短测杆，归档 L109 系列）；当前在用长测杆 L600
- **靶点位置（设备系）**：`root + [0, 0, −length]`，靶点在 Z 负向

`config.toml` 中 `device.geometry.probe_rod` 段维护这两个参数。


## 6. 测量约定

### 6.1 关节臂靶球

关节臂测量使用直径 **3 mm** 的靶球（半径 **1.5 mm**）。

记录的坐标是**靶球球心**位置，**不是物理表面**。要恢复物理表面，需要沿"外法向"（靶球贴的那一侧）把面向内收缩 1.5 mm。

### 6.2 面间距校正

当相邻两个面的靶球**从两侧相对凸出**时（典型如毛玻璃远相机面 ↔ 取景框近相机面，球心都向中间凸），两面之间的"物理距离" = "球心距离" − 2 × 1.5 mm。

当两个面**朝同一方向**时不需要这个校正。

### 6.3 与算法 Z=0 平面的关系

PnP 取景框位姿计算时把取景框平面视作 PnP 的 `Z = 0`，对应到设备坐标系也是 `Z = 0`。这两个 Z=0 是同一个面（毛玻璃近相机面 = 取景框远相机面）。

如果未来想把"承接屏远相机面"（实际激光打的面）作为算法实像面，需要相对当前的 Z = 0 向 Z 正方向偏移 3 mm。


## 7. 与实测的对照

详细对照见 `dataset/关节臂标定数据/0615/README.md`。简表：

| 物理量 | 结构标称 | 关节臂实测 | 说明 |
|---|---|---|---|
| 取景框 + 毛玻璃总厚 | 5 mm | 4.78 / 5.00 mm | 前后模块各一次 |
| 反射镜与承接屏夹角 | 45° | 45.22° | 偏差 0.22° |
| 反射镜厚度 | ~1 mm | 1.04 / 1.06 mm | 镜片两面平行 < 0.06° |
| 模块间距（承接屏面内） | 80 mm | 79.74 mm | 一致 |

绝对位置（Z 偏置、反射镜中心到 Z=0 面的距离等）需要下次采样补一个"承接屏中心"靶球点才能对齐。
