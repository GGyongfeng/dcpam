# 标定与数据版本说明

当前实验数据需要按采集批次区分标定版本。V1 和 V2 的图片虽然目录结构相同，
但它们对应的相机状态不同，不能把一个版本的图片和另一个版本的内参混用。

## 版本边界

V1 是最早一批数据，对应 `dataset/L109D20`、`dataset/L109D40`、
`dataset/L109D60`，现有 `dataset/1-Spot-Center.csv` 也是这一批图片的圆心结果。
V1 使用原始 OPENCV 内参，以及当时 `calibration.toml` 中的前后相机标定参数。

V2 是加垫圈后重新采集的数据，对应 `dataset/L109D20-v2`、
`dataset/L109D40-v2`、`dataset/L109D60-v2`。后续实验优先使用 V2 数据，
因此圆心结果需要重新提取，并单独保存为 `dataset/1-Spot-Center-v2.csv`。

## 使用约定

圆心提取只依赖图片本身，不直接使用内参；但圆心后续从像素坐标反投影到
相机坐标系时，必须使用与图片同版本的内参。也就是说：

- V1 图片使用 V1 内参和 V1 圆心表；
- V2 图片使用 V2 内参和 V2 圆心表；
- 如果垫圈改变的不只是焦距/焦圈，而是相机物理位置或屏幕相对位置，
  则平面外参和前后相机相对变换也需要重新标定，不能只替换内参。

目前项目默认配置已经切到 V2 内参，用于后续 V2 实验。
