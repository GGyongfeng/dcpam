# C1/C2/P1/P2 约束关系

本文定义前后相机、前后实像面之间的几何关系，作为后续标定一致性分析的共同语言。

## 变量定义

`C1` 表示前相机坐标系，原点在前相机光心，`+Z` 沿前相机光轴向外。

`C2` 表示后相机坐标系，原点在后相机光心，`+Z` 沿后相机光轴向外。

`P1` 表示前实像面坐标系。它对应前模块毛玻璃片被拍摄的实像面，也就是设备前取景框附近那一面。

`P2` 表示后实像面坐标系。它对应后模块毛玻璃片被拍摄的实像面。

设备坐标系，也就是主坐标系，定义在前取景框中心点。当前约定前取景框中心为设备坐标系原点，设备上的前后设备实像面、反射面和探测杆位置都在这个坐标系下表达。

这里需要区分两个概念。设备上的物理基准面叫“设备实像面”，也就是毛玻璃后面、取景框前面、位于设备坐标系 `Z=0` 的那一面。PnP 实像面则是用 PnP 目标定位得到的相机坐标系下的实像面估计。我们的核心工作，是把 PnP 实像面坐标系与设备坐标系中的设备实像面对齐。

## 四条核心关系

在 `C1`、`C2`、`P1`、`P2` 之间，当前关注三条关系：

```text
C1 -- P1
P1 -- P2
C2 -- P2
```

`C1 -- P1` 描述前相机与前实像面之间的位姿关系。当前主链路通过取景框图像做 PnP 目标定位得到。

`C2 -- P2` 描述后相机与后实像面之间的位姿关系，同样通过 PnP 目标定位得到。

`P1 -- P2` 描述前后实像面之间的设备硬件约束。当前它由设备坐标系中的前后设备实像面位置决定。也就是说，一旦前端模块和后端模块分别把标定实像面与各自设备实像面对齐，`P1` 和 `P2` 的相对关系就由硬件尺寸确定，从而把两个相机系下的算法量都搬入设备坐标系。

历史上还有 `C1 -- C2` 这条关系，描述前后相机的外参转换矩阵。它由微距镜头标定，两相机无法对同一成像面合焦，矩阵可靠性不足，当前主链路不再使用，也不在 `config.toml` 中保存。

## 当前 C-P 约束来源

对于 `C1 -- P1` 和 `C2 -- P2`，当前只使用 5 圆点 PnP 定位法。每个成像面上贴 5 个黑圆点，其在成像面局部坐标系下的 3D 坐标由影像仪测出作为 object points；标定时用 SimpleBlobDetector 从相机图提取 5 个圆心像素，结合相机内参与 object points 求解成像面局部系到相机坐标系的位姿：

```text
P_camera = R_frame_to_camera · P_frame + t_frame_to_camera
```

在 `config.toml` 中，这类结果保存为：

```text
calibration.frame_surfaces.front_frame_pnp
calibration.frame_surfaces.rear_frame_pnp
```

PnP 实像面会与设备坐标系中的设备实像面重合。重合之后，设备几何中的反射面也能被转换到各自相机坐标系下，作为镜像变换的反射面。

## 过约束与校验

当 `C1 -- P1`、`C2 -- P2`、`P1 -- P2` 都存在时，这个系统已经形成闭环。

推荐的校验方式是：

```text
1. 利用 C1--P1 把前相机系下的算法量搬入设备坐标系。
2. 利用 C2--P2 把后相机系下的算法量搬入设备坐标系。
3. 检查二者在 P1--P2 约束下的几何一致性，例如两个虚像点是否落在同一激光基准线上。
```

比较平面时，可以看两个指标：法向夹角，以及一个平面的代表点到另一个平面的有符号距离。

如果闭环误差较大，优先检查几件事：5 圆点圆心提取是否准确、object points 是否与影像仪最新测量一致，所有平移是否已经统一为毫米，以及设备坐标系下 `P1 -- P2` 的硬件尺寸是否与实物一致。

## 当前使用建议

当前主链路只保留 PnP 实像面和设备几何反射面。长期更稳妥的做法是建立一个小的标定一致性报告：输入当前 `config.toml`，自动输出 `C1--P1`、`C2--P2`、`P1--P2` 的误差。这样每次重标定后，都能快速判断是相机内参、取景框 PnP，还是设备几何尺寸出现了偏差。
