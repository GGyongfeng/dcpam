DCPAM Pipeline 对比报告

数据来源： dataset/spot-measurements.csv 与 dataset/spot-measurements-device.csv。 本报告比较两种方法得到的靶点到激光线距离，单位均为 mm。

方法 A：相机外参统一法

先在 C1、C2 各自相机坐标系下完成实像面反投影和镜像反射， 然后使用 C2 到 C1 的外参矩阵把后虚像点统一到 C1 坐标系， 最后在 C1 坐标系下计算靶点到激光线距离。

方法 B：设备坐标系统一法

先在各自相机坐标系下反投影到实像面，再通过 PnP 实像面与设备实像面 的对齐关系转到设备坐标系。镜像反射和距离计算都在设备坐标系中完成， 不使用 C2 到 C1 外参作为几何约束。

新方法 Pipeline

1. 提取圆心得到前后相机像素 UV。
2. 反投影到实像面得到 C1/C2 坐标系下实像点。
3. 转到设备坐标系使用 PnP 面与设备面重合关系。
4. 设备系镜像根据设备几何反射面生成虚像点。
5. 计算距离靶点与激光线都位于设备坐标系。

稳定性结论

均值差主要反映两种方法的系统偏移：当前所有组里方法 B 都比方法 A 小， 平均约小 0.404 mm。稳定性需要看同一组内的波动， 因此本报告重点比较 标准差 和 极差。 表格中的 B-A 标准差差值 与 B-A 极差差值 如果为负，表示方法 B 在该组更稳定。
