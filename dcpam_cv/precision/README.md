# 精度分析模型 - 问题描述

## 坐标系统
- 采用 xyz 笛卡尔坐标系
- 单位：1 格 = 1 cm

## 几何模型

### 接收屏设置
- **前接收屏**：位于 x = +5 cm
  - 尺寸：2cm × 2cm
  - 接收点：P_f (x_f, y_f, z_f)

- **后接收屏**：位于 x = -5 cm
  - 尺寸：2cm × 2cm
  - 接收点：P_b (x_b, y_b, z_b)

### 点位置定义

#### P_f 和 P_b（接收屏上的点）
- **x 坐标**：固定
  - x_f = +5 cm
  - x_b = -5 cm

- **y, z 坐标**：测量值（带误差）
  - y_f, z_f：P_f 的 y, z 坐标测量值
  - y_b, z_b：P_b 的 y, z 坐标测量值
  - **测量误差范围**：约 ±1 μm (±0.001 cm)

#### P_t（目标点）
- **z 坐标**：可调参数
  - 范围：-1000 cm 到 -2000 cm
  - 可输入变量

- **x, y 坐标**：待定（可能固定或可调）

### 直线 L
- 由 P_f 和 P_b 两点确定的直线

## 分析目标

### 核心计算量
**h**：点 P_t 到直线 L 的距离（点到直线距离）

### 研究问题
分析测量误差对目标计算量 h 的影响：
- **输入误差**：y_f, z_f, y_b, z_b 的测量误差（±1 μm）
- **输出精度**：h 的计算精度/重复性

### 误差变量
所有误差变量均可调节：
- `yf`：P_f 的 y 坐标误差
- `zf`：P_f 的 z 坐标误差
- `yb`：P_b 的 y 坐标误差
- `zb`：P_b 的 z 坐标误差

## 分析方法

### 1. 误差传播公式（解析法）
- 计算偏导数：∂h/∂yf, ∂h/∂zf, ∂h/∂yb, ∂h/∂zb
- 估算 h 的标准差 σ_h

### 2. 蒙特卡洛模拟
- 在 ±1 μm 范围内随机采样
- 统计 h 的分布特性
- 输出：
  - h 的标准差 σ_h
  - 95% 置信区间
  - 分布直方图

### 3. 敏感性分析
- 单独改变各参数，观察 Δh
- 识别关键误差源

### 4. 可视化
- 3D 空间模型（点和直线）
- h 值分布直方图
- 敏感性条形图

## 实现工具
- Python + NumPy（计算）
- Matplotlib（可视化）
